# Tech Stack — Operis UI

Visão geral de todas as tecnologias utilizadas no projeto.

---

## Framework & Linguagem

| Tecnologia | Versão | Descrição |
|------------|--------|-----------|
| Next.js | 15 | Framework React com suporte a App Router, SSR, SSG e middleware nativo. Base de toda a aplicação. |
| React | 19 | Biblioteca para construção de interfaces de utilizador baseadas em componentes. |
| TypeScript | 5 | Superset do JavaScript com tipagem estática. Garante maior segurança e produtividade no desenvolvimento. |

---

## Estilos

| Tecnologia | Versão | Descrição |
|------------|--------|-----------|
| Tailwind CSS | 4 | Framework CSS utility-first que permite estilizar componentes diretamente no JSX, sem conflitos de CSS global. |

---

## Qualidade de Código

| Tecnologia | Versão | Descrição |
|------------|--------|-----------|
| ESLint | 9 | Ferramenta de análise estática de código que identifica e corrige problemas no JavaScript/TypeScript. |

---

## Ferramentas de Desenvolvimento

| Tecnologia | Versão | Descrição |
|------------|--------|-----------|
| VS Code | - | Editor de código principal. Oferece excelente suporte a TypeScript, React e integração com Git. |
| Node.js | 24.11.1 | Runtime JavaScript utilizado para executar o servidor de desenvolvimento e gerir dependências. |
| npm | 11.6.2 | Gestor de pacotes do Node.js. Utilizado para instalar e gerir as dependências do projeto. |
| Git | - | Sistema de controlo de versões distribuído. |
| Gitflow | - | Estratégia de branching para Git que define um modelo claro de branches para features, releases e hotfixes. |

---

## Integração

| Tecnologia | Versão | Descrição |
|------------|--------|-----------|
| Guard API | - | Serviço de autenticação e autorização do ecossistema Operis. Fornece JWT com contexto multi-tenant. |
